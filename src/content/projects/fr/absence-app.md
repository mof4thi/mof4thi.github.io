Une application client-serveur pour enregistrer et suivre les absences.

- **Client :** Flutter (Dart), sur le web et sur Android.
- **Back-end :** une API REST en PHP.
- **Base de données :** MySQL, avec le schéma et les données initiales fournis sous forme de script SQL.

Le dépôt contient des captures d’écran, le schéma de la base de données et les étapes d’installation pour la lancer en local avec XAMPP.
