A client and server app for recording and tracking absences.

- **Client:** Flutter (Dart), running on the web and on Android.
- **Back end:** a PHP REST API.
- **Database:** MySQL, with the schema and seed data provided as an SQL script.

The repository includes screenshots, the database diagram and setup steps for running it locally with XAMPP.
